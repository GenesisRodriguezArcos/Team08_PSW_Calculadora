# Calculadora - Team08_PSW

## Descripción

Calculadora que permite realizar operaciones matemáticas básicas (suma, resta, multiplicación, división) y avanzadas (potencia, raíz cuadrada, factorial, MCD, MCM, entre otras).

## Tecnologías

- **Java 11**
- **Maven** - Gestor de dependencias
- **JUnit 5** - Pruebas unitarias
